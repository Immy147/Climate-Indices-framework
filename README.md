# Climate-Indices-framework
Modular, tested Python pipeline for computing ETCCDI climate extreme indices (TXx, TX90p, WSDI, RX1day, CDD, R95p, and more) from daily tasmax/pr NetCDF data. Dask-backed for large CMIP6/CORDEX/ISIMIP-scale datasets, with validation, cleaning, trend analysis (Mann-Kendall), and multi-format export built in.
